# 8. 사업화 전략

> **작성 상태:** 세부 내용 작성 완료
>
> **핵심 결론:** 본 사업은 개발기업이 지자체·공공 방역기관에 자동검사 장치와 AI 조기경보 플랫폼을 공급하고, 공공기관이 관할 고위험 가금농장에 시스템을 설치·운영하여 농장과 지역 방역체계가 함께 사용하는 B2G2B 사업이다. 사업화는 자동검사 MVP 개발, 전문기관 공동검증, 충북 공공실증, 유료 시범사업, 공공조달 및 지역 단위 확산 순서로 추진한다.

본 사업의 핵심 거래와 서비스 구조는 다음과 같다.

~~~text
[개발기업 Business]

자동검사 장치
Composite Cartridge·검사 소모품
AI Early Warning Platform
설치·교육·유지보수
        ↓ 공급·운영

[지자체·공공 방역기관 Government]

예산 확보
실증·조달 발주
대상 농장 선정
지역 위험상황 관제
전문기관 확인검사 연결
        ↓ 농장 배포·운영관리

[가금농장·계열화사업자 Business]

장치 현장 사용
계분벨트 운전 협조
경보·재검 절차 수행
농장 운영데이터 제공
        ↓ 검사·운영 데이터

[정부 관제 및 공식 방역체계]

위험농장 우선순위 확인
현장점검·시료채취
전문기관 공식검사
필요한 법정 방역조치
~~~

계약만 보면 기업이 정부에 공급하는 B2G 거래지만, 정부가 구매한 서비스를 농장기업에 배포하고 지역 방역에 활용하므로 전체 사업모델은 B2G2B로 정의한다.

가금농장과 계열화사업자는 중요한 현장 사용자이지만, 초기 핵심 구매자는 아니다. 초기 설치비와 운영비는 지자체·공공 실증사업이 부담하고, 농장은 참여농가로서 장치 운영과 재검·공식검사 연결 절차에 협조하는 구조를 기본으로 한다.

## 서면평가 ‘사업화’ 대응 요약

사업화 가능성은 잠재 농가 수에 임의의 단가를 곱한 시장규모가 아니라, **지자체가 어떤 문제를 해결하기 위해 무엇을 계약하고 농장·전문기관이 어떻게 운영하는지**를 보여주는 실행경로로 입증한다.

| 사업화 판단요소 | 현재 계획 | 공모전 이후 확보할 증거 |
|---|---|---|
| 핵심 구매자 | 충북도·시군 및 공공 방역기관 | 수요기관 인터뷰, 문제·예산·조달경로 확인 |
| 현장 사용자 | 계분벨트식 산란계·종계 농장 관리자 | 설치환경 조사, 사용자 업무흐름과 참여의사 |
| 검증 파트너 | 동물위생시험소·대학·수의·진단 전문기관 후보 | 역할협의, 시험계획 승인 또는 협력의향 |
| 초기 계약단위 | 1개 지자체·소수 농가의 범위가 명확한 실증 | 장비수, 기간, KPI, 책임과 종료조건이 있는 제안서 |
| 제공가치 | 반복 검사데이터와 공식검사 우선순위, 관제·유지관리 | 선행시간, 경보 후 조치시간, 가동률과 사용자평가 |
| 수익구조 | 장치 구축 + 연간 관제·유지관리 + 검사량 연동 소모품 | BOM·OEM·키트·클라우드·A/S 복수견적 |
| 확산조건 | 기술·규제·현장·경제성 Gate 통과 | 유료실증, 재계약 또는 다음 지역 수요 확인 |

### 고객 검증의 단계와 표현원칙

1. **공모전 단계:** 공식 통계·정책·예산으로 문제와 공공수요의 존재를 설명한다.
2. **선정 직후:** 지자체·농가·전문기관 인터뷰로 실제 업무흐름, 설치조건, 조달 가능성과 협력범위를 확인한다.
3. **시제품 사양 확정 전:** 키트사·OEM·부품사·클라우드·유지보수 후보의 복수견적으로 원가와 공급조건을 갱신한다.
4. **실증 제안 단계:** 기간, 장비수, 대상농장, 데이터권한, KPI, 책임과 중단조건을 문서화한다.
5. **사업성 판단 단계:** 무상 관심표현보다 유료실증, 반복사용, 재계약과 다른 지역의 후속수요를 우선 증거로 사용한다.

아직 확보하지 않은 인터뷰, 협력의향서, 견적, 허가, 구매의사와 실증성과는 현재 보유한 것처럼 표현하지 않는다. 공모전 이후 확인결과가 현재 가정과 다르면 고객범위·제품사양·가격·일정을 함께 수정한다.

### 초기 도입 의사결정 기준

| 구분 | Go 조건 | 보완 또는 중단 조건 |
|---|---|---|
| 기술 | 안전한 Mock에서 End-to-End 반복동작과 데이터 추적 가능 | 누액·오염·반복실패를 통제하지 못함 |
| 키트·규제 | 허용검체·자동화 범위와 제품분류 경로 확인 | IFU·규제조건과 핵심 사용목적이 양립하지 않음 |
| 현장 | 계분벨트 간섭 없이 설치·운영 가능 | 설치공간·세척·폐기·정비 부담이 수용 불가 |
| 고객 | 수요기관이 해결문제·성과지표·담당부서를 확인 | 관심은 있으나 책임부서·예산·운영주체가 없음 |
| 경제성 | 복수견적 기준의 총소유비용과 잠재편익을 비교 가능 | 소모품·유지관리비가 편익과 예산범위를 지속 초과 |
| 확산 | 유료실증 성과와 재계약·후속지역 수요 확보 | 장기 무상실증만 반복되고 구매전환 근거가 없음 |

## 공모전 단계 사업화 범위

| 구분 | 공모전 단계 | 공모전 이후 실행 |
|---|---|---|
| 고객 | 지자체·전문기관·농장 역할과 B2G2B 구조 제안 | 인터뷰, 협력의향서, 유료실증 협의 |
| 제품 | MVP 구성·제외기능·Gate 정의 | 시제품·전문검증·현장 사용평가 |
| 가격 | 9장의 내부추정 시나리오 | 공급사·OEM·클라우드·A/S 견적 |
| 조달 | 벤처나라·혁신제품 등 가능한 경로 검토 | 기업·제품요건 충족 후 신청 |
| 성과 | 검증할 KPI와 산출물 정의 | 유료계약·재계약·공공성과 확인 |

공모전 선정 자체를 제품검증, 구매의사 또는 조달자격으로 해석하지 않는다. 선정 이후 가장 먼저 고객 인터뷰와 Gate 0 규제·키트·현장 검토를 수행하고, 장기 무상실증보다 범위와 종료조건이 명확한 기능검증을 우선한다.

## 8.1 MVP 개발 계획

### 1. B2G2B형 MVP 정의

초기 MVP는 농장에 설치하는 장치만으로 구성하지 않는다. 공공기관이 여러 참여농장을 관리할 수 있도록 Farm Edge, Public Control, Service Operation의 세 계층을 함께 개발한다.

| 구성계층 | 주요 사용자 | MVP 핵심기능 |
|---|---|---|
| Farm Edge | 농장 관리자 | 반복 분변검사, 장치상태 확인, 재검 안내, 소모품 알림 |
| Public Control | 지자체·방역담당자 | 참여농장 현황, Risk Level, 반복경보, 재검상태, 확인 대상 우선순위 |
| Service Operation | 개발기업 운영자 | 장치 원격점검, 장애관리, 소모품·버전·교정이력, 유지보수 |
| Verification Interface | 전문기관 | 장치 검사이력, 시료 식별자, 공식검사 결과 비교, 실증자료 내보내기 |

### 2. Farm Edge MVP

현장 장치는 현재 설계기준인 **1 Sampling Point / 1 Analysis Unit**으로 개발한다.

주요 기능은 다음과 같다.

- 계분벨트 운전상태 감지
- 여러 시점의 반복 소량채취
- Composite Sample 생성
- 일회용 전처리 카트리지 장착
- 시료와 완충액 혼합
- 고형물 침전과 상층액 채취
- 상용 AIV 신속항원키트 자동분주
- 검사시간 자동관리
- 고정 카메라·조명 기반 C선·T선 촬영
- 양성·음성·무효 정성판독
- T/C 반정량 optical signal 기록
- 검사 QC와 장치상태 저장
- 이상신호 발생 시 동일 조건 자동 재검
- 통신 장애 시 엣지 저장 및 복구 후 동기화

검체접촉부는 Composite Cartridge, 튜브 및 팁 등 일회용 Wet Zone으로 제한하고, 모터·카메라·제어기·통신장치 등은 재사용하는 Dry Zone으로 구성한다.

### 3. Public Control MVP

B2G2B 사업에서는 농장용 장치와 함께 공공 관제기능이 반드시 필요하다.

초기 공공 관제화면에는 다음 기능을 포함한다.

- 사업에 참여하는 농장·계사·Sampling Point 목록
- 농장별 최근 검사결과
- NORMAL·WATCH·CAUTION·ALERT 위험단계
- 최근 N회 T/C 신호 변화
- 반복경보와 자동 재검 결과
- 무효검사와 장치 QC 상태
- 경보 발생시각과 관리자 확인상태
- 현장점검·공식검사 권고상태
- 장치 가동률과 소모품 상태
- 사용자·기관별 접근권한
- 경보 확인 및 조치 이력
- 실증·평가용 보고서 내보내기

초기 Risk Engine은 규칙기반과 통계적 이상탐지로 구현한다. 충분한 공식검사 Label이 축적되기 전까지 머신러닝이 감염 여부를 예측하거나 확정하는 구조를 적용하지 않는다.

### 4. 초기 MVP에서 제외할 기능

다음 기능은 첫 번째 공공실증 MVP에서 제외한다.

- 머신러닝 기반 AIV 확진
- T/C 값의 바이러스량 환산
- 한 개 Sampling Point의 축사 전체 대표성 단정
- Multi-point 통합 위험판정
- KAHIS 또는 축산차량 GPS 직접연계
- 실제 이동이력 기반 Epidemiological Risk Graph
- 감염경로 자동판정
- 법정 이동제한·살처분 자동결정
- 육계·오리농장용 별도 Sampling 방식
- 다른 가축전염병으로의 확대

Epidemiological Risk Graph의 데이터 구조와 화면 Prototype은 개발할 수 있지만, 초기에는 Mock 데이터나 참여농장이 정당하게 제공한 자체 데이터를 사용한다. 공식 이동이력은 기관 협력과 이용권한이 확보된 이후에만 연계한다.

### 5. 단계별 개발 관문

| 단계 | 주요 개발·검증내용 | 통과조건 |
|---|---|---|
| Gate 0. 사업·규제 정의 | 공공 수요조사, 사용목적 확정, 규제분류 사전상담 | 제품범위·실증범위·허가전략 문서화 |
| Gate 1. Analysis MVP | 혼합·침전·상층액 채취·분주·카메라 판독 | 안전한 Mock 조건에서 반복동작 확인 |
| Gate 2. Sampling 통합 | 계분벨트 반복채취와 Composite Sample 생성 | 벨트 운전방해 없이 시료 생성 |
| Gate 3. Platform 통합 | 농장·공공·운영화면과 검사데이터 연결 | 장치부터 관제까지 전체 데이터 추적 |
| Gate 4. 전문기관 검증 | 기준검사 비교계획, 시료안전, T/C 검증 | 전문기관 승인 시험계획 확보 |
| Gate 5. 농장 운영실증 | 가동률, 검사 유효성, 유지관리, 사용자 절차 | 공공 유료실증 제안이 가능한 증거 확보 |

통과기준의 구체적인 수치는 6장의 기능검증과 현장실증에서 기준값을 측정한 뒤 확정한다.

### 6. 규제·품질 준비

본 시스템은 AIV 위험선별을 사용목적으로 하는 장치와 소프트웨어이므로, “확진장비가 아니다”라는 표현만으로 규제대상에서 제외된다고 가정하지 않는다. 사용목적에 따라 동물용의료기기 또는 동물용체외진단의료기기 해당 여부를 검토해야 한다.

MVP 설계 확정 전에 다음을 확인한다.

- 장치 본체와 소프트웨어의 품목 분류
- 제조업허가·품목허가·신고 필요 여부
- 상용 AIV 키트와 자동검사장치의 결합제품 해당 여부
- 키트의 허용검체에 분변·Composite Sample이 포함되는지
- 자체 전처리와 상층액 사용이 허가범위에 부합하는지
- 연구시험용 장치와 판매용 장치의 구분
- OEM 생산 시 제조자·품목허가자·판매자의 책임
- 일회용 카트리지의 품질관리와 추적성
- 소프트웨어·알고리즘 변경관리
- 장치 안전성·세척·소독·폐기 절차

## 8.2 초기 실증시장 진입

### 1. 초기 실증의 사업단위

초기 사업단위는 장치 한 대를 농장에 판매하는 것이 아니다.

> **한 개 지자체 또는 공공 방역기관이 주관하고, 전문 검증기관과 소수 협력농장이 참여하는 지역 단위 B2G2B 실증사업**

권장 구성은 다음과 같다.

| 참여주체 | 역할 |
|---|---|
| 충청북도·시군 등 수요기관 | 사업주관, 예산, 농장 선정, 방역절차 연결 |
| 동물위생시험소 등 전문기관 | 공식검사 비교, 시료안전, 성능검증 |
| 개발기업 | 장치·플랫폼 공급, 설치, 교육, 유지보수 |
| 협력 산란계 농장 | 설치공간, 계분벨트 운영, 현장절차 수행 |
| 계열화사업자·생산자단체 | 참여농장 조정, 현장확산, 운영의견 제공 |
| 대학·연구기관 | 시험설계, 데이터 분석, 결과 검토 |

충북 동물위생시험소는 조류인플루엔자 정밀진단과 상시예찰 업무를 수행하고 있으므로 기준검사 비교와 방역절차 자문을 요청할 수 있는 후보 기관이다. 다만 실제 협력은 공식 제안과 기관 승인을 전제로 한다.

### 2. 초기 실증지역과 대상 농장

초기 실증지역은 충청북도로 설정한다. 현재 장치는 계분벨트 끝단을 Sampling Point로 사용하므로, 첫 번째 실증대상은 다음 조건을 충족하는 농장으로 좁힌다.

- 계분벨트식 사육시설을 갖춘 산란계·종계 농장
- 스크레이퍼 이후 낙하구간에 장치를 설치할 수 있는 농장
- 벨트 운전시간 또는 운전신호를 확보할 수 있는 농장
- 전원·통신·장치 고정공간을 확보할 수 있는 농장
- 장기운전과 정기점검에 협조할 수 있는 농장
- 재검·관리자 확인·전문기관 연락절차를 수행할 수 있는 농장
- 실증데이터의 비식별 활용에 동의할 수 있는 농장
- 농장 출입·세척·소독 등 방역수칙을 준수할 수 있는 농장

현재 계분벨트 Sampling 구조를 그대로 적용하기 어려운 깔짚식 육계·오리농장은 초기 설치대상에서 제외한다. 해당 시장은 별도의 Sampling Node를 개발하고 성능을 새로 검증한 이후 확장한다.

### 3. 실증 진입 순서

#### STEP 1. 안전한 Mock 검증

- 비감염 모사시료를 사용한 채취·전처리·분주 반복성 확인
- 고형물 침전과 상층액 채취조건 확인
- 키트 장착·분주·판독시간 제어
- 카메라 C선·T선 판독과 QC 확인
- 장치고장·정전·통신장애 대응시험

#### STEP 2. 시험계사·정상농장 운영검증

- 분진·습기·온도·암모니아 환경에서의 내구성 확인
- 계분벨트 운전에 대한 물리적 간섭 확인
- 정상 시기의 농장별 기준선 축적
- 무효검사와 오경보 원인분석
- 소모품 교체와 작업자 개입시간 측정

#### STEP 3. 전문기관 공동 비교검증

- 상용 키트 허용검체와 전처리조건 확인
- 장치결과와 수동 키트 판독 비교
- 전문기관 기준검사와의 paired data 확보
- T/C 반정량 신호의 재현성과 해석범위 검증
- 자동 재검조건과 경보규칙 검토

감염성 AIV 시료와 공식검사에 해당하는 시험은 적절한 시설과 권한을 갖춘 전문기관에서 수행한다.

#### STEP 4. 소수 농장 장기실증

- 장치 가동률과 유효검사율
- Sampling·전처리·분주 성공률
- 농장별 기준선과 시계열 변동
- 자동 재검의 작동과 사용자 대응
- 유지보수 횟수와 장애복구시간
- 유효검사 1회당 소모품·운영비
- 공공 관제화면의 활용성

#### STEP 5. B2G2B 대응 모의훈련

실제 위험신호를 가정하여 다음 흐름이 작동하는지 확인한다.

~~~text
장치 이상신호
    ↓
자동 QC·재검
    ↓
농장 관리자 확인
    ↓
지자체 관제담당자 알림
    ↓
전문기관 확인 필요성 검토
    ↓
공식 시료채취·검사 절차 연결
    ↓
조치결과 기록
~~~

### 4. 실증 산출물

공공조달로 전환하기 위해 다음 자료를 확보한다.

- 설치환경 및 표준 설치절차
- 장치·소모품 규격서
- Sampling·전처리·판독 검증보고서
- 전문기관 기준검사 비교자료
- 농장 장기운영 결과
- 오경보·무효·장애 사례분석
- 사용자별 표준운영절차
- 경보 발생 시 대응 매뉴얼
- 데이터 보안·권한·보존정책
- 유지보수와 소모품 공급계획
- 유효검사 1회당 비용
- 공공 수요기관의 사용평가서

## 8.3 고객 확보 전략

### 1. 핵심 고객 구조

본 사업에서 고객과 사용자를 다음과 같이 구분한다.

| 구분 | 대상 | 사업상 위치 |
|---|---|---|
| 핵심 구매자 | 중앙정부·지자체·공공 방역기관 | 예산·실증·조달 발주 주체 |
| 현장 사용자 | 산란계 농장 관리자 | 장치 사용과 경보 대응 주체 |
| 전문 사용자 | 동물위생시험소·수의방역기관 | 공식검사와 방역 연결 주체 |
| 확산 파트너 | 계열화사업자·생산자단체 | 참여농장 조정과 현장확산 |
| 운영 공급자 | 개발기업 | 장치·플랫폼·소모품·유지보수 공급 |

계열화사업자와 대규모 농장의 직접구매는 보조적인 B2B 판로로 유지하되, 사업계획서의 핵심 시장진입은 B2G2B로 설정한다.

### 2. 정부 고객에게 제공하는 가치

지자체와 공공 방역기관에는 다음 가치를 제안한다.

- 관할 참여농장의 반복검사 현황 통합관리
- 공식검사 사이의 농장 내부 관찰정보 확보
- 반복 이상과 자동 재검을 반영한 확인 우선순위
- 검사결과뿐 아니라 장치·시료·판독 QC 제공
- 경보부터 현장확인·공식검사까지의 이력관리
- 제한된 방역인력의 현장점검 우선순위 지원
- 지역 단위 실증·성과평가 자료 자동생성
- 향후 농장·차량·시설 이동관계 분석으로의 확장성

검증 전에는 조기경보로 살처분이나 공공비용을 일정 비율 절감한다고 주장하지 않는다. 실증에서 실제 경보 선행시간, 대응시간, 추가 확인검사비와 운영비를 측정한 뒤 순효과를 평가한다.

### 3. 농장기업에 제공하는 가치

농장은 정부가 제공하는 방역서비스의 현장 사용자로서 다음 가치를 얻는다.

- 수동검사 작업 일부 자동화
- 공식검사 사이의 반복적인 농장 내부 감시
- 장치상태·검사결과·재검상태 확인
- 이상신호 발생 시 정해진 대응절차 제공
- 과거 검사·경보·조치 이력 보존
- 공공 방역기관과의 신속한 정보공유
- 장비 설치와 운영비에 대한 공공지원 가능성

농장에는 확진 결과가 아니라 위험단계, 판단 이유, 재검상태와 권고 조치를 제공한다.

지자체에 제출하는 실증 제안서는 다음 내용을 포함한다.

- 기존 방역체계에서 해결하려는 구체적 운영 공백
- 본 시스템과 공식검사의 역할 구분
- 설치대상 농장 선정기준
- 장치·소모품·플랫폼 공급범위
- 전문기관 비교검증 방법
- 농장·지자체·기업의 업무분담
- 경보 발생 시 연락·재검·공식검사 절차
- 실증 KPI와 중단조건
- 데이터 접근권한·보안·비식별화
- 설치·교육·유지보수 계획
- 비용항목과 계약범위
- 실증 종료 후 구매·철거·데이터 처리방식

무상실증은 제한된 기능검증 범위에서만 수행한다. 장기 농장운영 단계에서는 공공 수요기관이 장치, 설치, 소모품 또는 관리서비스에 대한 예산을 부담하는 유료 시범사업으로 전환하여 실제 공공수요와 사업 지속가능성을 확인한다.

### 4. Epidemiological Risk Graph 협력

세 번째 핵심기술은 초기부터 데이터 접근을 전제하지 않는다.

- 1단계: Mock Farm·Vehicle·Visit 데이터로 Graph 구조 개발
- 2단계: 참여농장이나 계열화사업자가 정당하게 보유한 데이터로 검증
- 3단계: 지자체·공공기관과 데이터 이용목적과 법적근거 협의
- 4단계: 허가된 최소범위의 이동관계 데이터 연계
- 5단계: 농장 Bio Risk와 Movement Risk를 결합해 확인 우선순위 제안

KAHIS를 대체하거나 공식 이동정보를 임의로 수집하지 않는다. 개인 실명보다 차량·업체·시설·시간 중심의 가명 식별자를 우선한다.

## 8.5 공공조달 및 확산 전략

### 1. 조달 진입 전 준비조건

공공조달 신청에 앞서 다음 조건을 갖춘다.

- 제품의 동물용의료기기·체외진단의료기기 분류 확인
- 필요한 제조업·품목허가·신고 절차 이행
- 상용 AIV 키트의 사용범위와 장치 호환성 확인
- 제품 규격서와 표준 설치조건
- 장치·소모품 생산 및 품질검사 체계
- 전문기관 비교검증 결과
- 농장 장기운영 실적
- 사용자 교육과 방역 SOP
- 원격점검·현장출동·장애복구 체계
- 소모품 공급과 폐기계획
- 데이터 보안·접근권한·감사로그
- 조달단가와 운영비의 산출근거
- 하자보수와 제품책임 범위

### 2. 조달 진입 순서

#### 1단계. 지자체 공공실증

지자체 또는 공공기관이 실증사업을 발주하고, 선정된 농장에 장치를 설치한다. 이 단계에서는 판매실적보다 기술·방역·운영·경제성 자료를 만드는 것을 우선한다.

#### 2단계. 유료 시범운영

실증결과가 기준을 충족하면 장치 임대, 소모품 공급, 플랫폼 운영과 유지보수를 묶은 유료 시범사업으로 전환한다.

#### 3단계. 벤처나라 진입

제품 규격, 생산주체, 품질자료와 A/S 체계가 갖춰지면 벤처나라 등록을 검토한다. 벤처나라는 창업·벤처기업이 직접 생산하거나 국내 OEM으로 생산하는 제품·서비스를 기술·품질심사 후 공공기관에 공급하는 초기 조달경로다.

#### 4단계. 혁신제품 지정·시범구매

공공성과 혁신성, 전문기관 검증 및 수요기관 실적이 확보되면 조달청 혁신제품 지정과 시범구매에 도전한다. 혁신제품 시범구매를 통해 공공기관이 제품을 실제로 사용하고 그 결과를 평가하도록 하여 초기 공공시장을 형성한다.

#### 5단계. 지역 단위 관리형 사업

단품 장비가 아니라 다음을 묶은 지역 단위 방역서비스로 확장한다.

- 농장별 Automated Bio-Surveillance Node
- Composite Cartridge와 검사키트
- AI Early Warning Platform
- 지자체 통합관제
- 설치·교육·정기점검
- 원격진단·현장 유지보수
- 데이터 분석과 실증·성과보고
- 향후 Multi-point 및 Movement Risk 기능

### 3. 지역 확산 순서

~~~text
충북 소수 계분벨트식 산란계 농장
        ↓
충북 고위험 산란계 농장군
        ↓
충청권·중부권 지자체
        ↓
계열화사업자 참여형 공공사업
        ↓
타 시·도 지역 단위 관제
        ↓
전국 공공조달·국가방역체계 연계
~~~

초기에는 유지보수 거리가 가까운 농장군에 집중한다. 설치지역을 무리하게 넓히기보다 한 지역에서 소모품 공급, 장애복구, 농장교육과 전문기관 연결절차를 먼저 안정화한다.

### 4. 확산 판단 KPI

| 평가영역 | 주요 KPI |
|---|---|
| 장치운영 | 가동률, Sampling 성공률, 전처리·분주 성공률 |
| 검사품질 | 유효검사율, 무효율, 재검 일치율, QC 실패율 |
| 경보성능 | 공식검사 비교성능, 오경보율, 미탐률 |
| 대응체계 | 경보 확인률, 재검 수행률, 공식검사 연결시간 |
| 현장운영 | 농장 작업시간, 점검횟수, 장애복구시간 |
| 경제성 | 유효검사 1회당 비용, 농장당 운영비, 유지보수비 |
| 공공활용 | 방역담당자 사용률, 확인 우선순위 활용건수 |
| 데이터품질 | 누락률, 공식검사 Label 확보율, 메타데이터 완전성 |
| 사업확산 | 유료실증 전환, 후속구매, 재계약, 참여농장 확대 |
| 기관협력 | 공식검사 연계, 데이터협약, 공동실증기관 수 |

구체적인 목표수치는 6장의 실증결과를 바탕으로 결정한다. 검증되지 않은 정확도, 경보 선행시간, 비용절감률과 피해예방액을 사업화 성과로 미리 확정하지 않는다.

### 5. 세 핵심기술의 사업화 확장

| 사업화 단계 | 공급제품 | 핵심기술 |
|---|---|---|
| 초기 공공실증 | 1 Sampling Point Node + 기본 공공관제 | Automated Bio-Surveillance Node |
| 유료 시범사업 | 반복검사·자동재검·Reason Codes | AI Early Warning Engine |
| 지역 확산 | 다농장 통합관제·Multi-point 선택 적용 | Node Network + AI Platform |
| 기관연계 실증 | 허가된 이동관계 기반 우선순위 | Epidemiological Risk Graph |
| 장기 공공사업 | 지역 단위 통합 위험관제 | Public Biosecurity Data Platform |

## 8장 종합 사업화 모델

본 사업의 최종 사업화 구조는 다음과 같다.

> **개발기업이 자동검사 장치, 일회용 검사 소모품, AI 조기경보 플랫폼과 유지관리 서비스를 지자체·공공 방역기관에 공급하고, 공공기관이 관할 고위험 농장에 시스템을 설치하여 농장 내부 반복검사와 지역 단위 위험관제를 수행하며, 이상신호를 전문기관의 확인검사와 공식 방역체계로 연결하는 B2G2B 가축방역 서비스**

사업화 성공의 기준은 장비 판매대수만이 아니다.

- 공공기관이 반복적으로 예산을 편성할 수 있는가
- 농장이 장치를 실제 방역절차 안에서 사용할 수 있는가
- 전문기관이 장치의 검사이력을 확인검사에 참고할 수 있는가
- 기업이 소모품·유지보수·플랫폼을 안정적으로 공급할 수 있는가
- 실증 후 유료사업과 후속조달로 전환되는가

8장에서는 이 시장진입 구조를 다루고, 구체적인 판매·임대·플랫폼 사용료와 수익성은 9장, 연도별 추진일정은 10장, 위험요소는 13장, 규제·제도 세부사항은 14장에서 작성한다.
